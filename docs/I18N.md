# English and Indonesian interface

English is the default. The header selector stores `scanpilot-language` in localStorage, with an in-memory fallback if storage is unavailable. The HTML `lang` attribute, accessible labels, navigation, guidance, quality summaries, process traces, source captions, and export annotations follow the selected language.

`static/translations.js` contains reviewed Indonesian/English message pairs with positional placeholders. `static/i18n.js` renders registered static copy and explicitly requested dynamic messages. It never observes arbitrary document mutations or translates OCR data. Uploaded filenames, OCR lines, amounts, coordinates, source IDs, and hashes remain unchanged. JSON schema keys stay language-neutral; a `language` field identifies the annotation language.

The original Indonesian API observations remain in memory so language switching does not rerun OCR or change the evidence. `localizedEvidence` makes a copy of human-readable report fields for export. Text and PDF annotations use the same catalog. Language switching is disabled during processing/export to avoid inconsistent output language.

Synthetic preview images follow the current UI language. Once a sample is selected, its language is retained for its second photo even if the UI language changes. Actual uploaded documents are never rewritten or translated.

## Maintaining copy

Add a message pair to the catalog and call `tr(source, values)` for dynamic copy. Use numbered placeholders for runtime data. Do not pass OCR text or user filenames directly to `tr`. Static text is registered once at startup; dynamically created controls must explicitly request their translations. Keep both language variants' placeholders identical.

## Checks

`node tests/test_i18n.cjs` checks dynamic templates, composite backend instructions, conflict errors, reversible switching, export localization, and preservation of OCR data.

`tools/check_languages_browser.py` uses the isolated Chrome test profile on CDP port 9225 and the app on port 8765. It exercises default English, preference persistence, switching with an active document, real English two-photo recovery, source views, errors, manual-region preservation, exports, user filenames, and responsive widths in both languages.

The historical master prompt, planning notes, and previous validation reports retain their original language and dates. `README.en.md` provides an English project entry point for reviewers.
